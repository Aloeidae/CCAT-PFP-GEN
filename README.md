# CCAT PFP Generator

Upload a portrait and receive an official state-issued ushanka. Powered by Runware image inference.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Set `RUNWARE_API_KEY` in `.env` (see `.env.example`)
3. Run the app:
   ```
   npm run dev
   ```
